Общие шаги (для всех телефонов)

Эти команды одинаковы для всех устройств. Сначала выполните их, затем перейдите к разделу своего телефона для дополнительных настроек.

1. Включить режим разработчика

Настройки → О телефоне → Номер сборки → нажмите 7 раз.

2. Включить отладку по USB

Настройки → Для разработчиков → Отладка по USB.

3. Подключить телефон

USB-кабель → в шторке «Передача файлов» → разрешите отладку на экране телефона.

Шаг 3.1 — Проверить подключение

Откройте PowerShell в папке platform-tools (Shift + правый клик → «Открыть окно PowerShell здесь»).

.\adb devices

Должно показать статус device.

Шаг 3.2 — Найти пакет (вводить именно сейчас)

После того как устройство в статусе device, выполните по очереди:

.\adb shell pm list packages | findstr -i gate
.\adb shell pm list packages | findstr -i cx
.\adb shell pm list packages | findstr -i qr
.\adb shell pm list packages | findstr -i scanner
.\adb shell pm list packages | findstr -i scan
Запомните найденный пакет (обычно ВАШ_ПАКЕТ или com.qrscanner.app).

Шаг 3.3 — Выдать разрешение

Только после того как нашли пакет:

.\adb shell appops set ВАШ_ПАКЕТ RECEIVE_SENSITIVE_NOTIFICATIONS allow

Замените ВАШ_ПАКЕТ на найденный пакет, если он другой.

4. Доступ к уведомлениям

Настройки → Приложения → Специальный доступ → Доступ к уведомлениям → включите приложение.

Полностью закройте приложение, перезагрузите телефон, запустите заново.

Realme

После общих шагов ADB выполните:

  • Настройки → Батарея → Оптимизация приложений → приложение → Не оптимизировать
  • Настройки → Приложения → Автозапуск → включите приложение
  • Настройки → Батарея → Управление приложениями в фоне → разрешите приложение
  • Отключите режим энергосбережения или добавьте приложение в исключения
Перезагрузите телефон после всех настроек.

Xiaomi / Redmi / POCO

  • Настройки → Приложения → Автозапуск → включите приложение
  • Настройки → Батарея → приложение → Без ограничений
  • Настройки → Приложения → приложение → Другие разрешения → включите нужные
  • В недавних приложениях заблокируйте приложение (замок)
На некоторых версиях MIUI отключите «Оптимизацию MIUI» в режиме разработчика.

Samsung

  • Настройки → Приложения → приложение → Батарея → Без ограничений
  • Настройки → Батарея и уход за устройством → Батарея → Ограничения фонового использования → удалите приложение из спящих
  • Настройки → Приложения → Специальный доступ → Оптимизация батареи → приложение → Не оптимизировать
  • В недавних приложениях заблокируйте приложение

Huawei / Honor

  • Настройки → Батарея → Запуск приложений → приложение → Управление вручную → включите все три пункта
  • Настройки → Приложения → приложение → Батарея → Игнорировать оптимизацию
  • В недавних приложениях заблокируйте приложение (замок)

Oppo / OnePlus

  • Настройки → Батарея → Оптимизация батареи → приложение → Не оптимизировать
  • Настройки → Автозапуск → включите приложение
  • Настройки → Батарея → Управление потреблением в фоне → приложение → Разрешить фоновую активность
  • В недавних приложениях заблокируйте приложение

Vivo

  • Настройки → Батарея → Фоновое потребление энергии → приложение → Не ограничивать
  • Настройки → Автозапуск → включите приложение
  • Настройки → Приложения → приложение → Батарея → Без ограничений
  • В недавних приложениях заблокируйте приложение

Если появляются ошибки

«device unauthorized»

Разрешите отладку на телефоне. Если окна нет — в «Для разработчиков» нажмите «Отзыв авторизации USB-отладки» и подключите снова.

.\adb kill-server
.\adb devices

«No UID for ... in user 0»

Неправильный пакет. Вернитесь к шагу 3.2 и найдите правильное имя.

«Имя adb не распознано»

Открывайте PowerShell из папки platform-tools и всегда пишите .\adb

Пустой результат при поиске пакета

Попробуйте все команды из шага 3.2. Если ничего не нашлось:

.\adb shell pm list packages
